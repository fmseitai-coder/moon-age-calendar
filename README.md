# moon-age-calendar

月齢カレンダー ― 月を知る、潮を知る。

月の満ち欠けを眺めるだけでなく、「なぜそうなるのか」まで学べる1ページのサイトです。
JavaScript と SVG だけで動作し、外部ライブラリは不要です。

公開ページ: https://fujitamario.com/molt/moon-age/

## 内容

- **今日の月**: 月齢・輝面比・潮回り・月までの距離・見かけの大きさ・次の満月/新月
- **月面ガイド**: 海やクレーターの位置と、いま光が当たっているかの表示
- **カレンダー**: 日ごとの月の姿と月齢。日付を選ぶとページ全体がその日の姿に変わる
- **解説**: 満ち欠けの仕組み／月がいつも同じ面を向ける理由（潮汐固定）／潮の満ち引きの仕組み／大潮と小潮／月の距離とスーパームーン

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | スタイル |
| `astro.js` | 月の位置の計算（Meeus の簡略式）。月齢・朔望・距離を求める |
| `app.js` | 画面の描画 |
| `img/full-moon.jpg` | 満月の写真。上に影を重ねて満ち欠けを表す |
| `moonage.js` | 旧版の埋め込み用ウィジェット（現在の `index.html` では未使用） |

サーバーに置くときは、`index.html` `style.css` `astro.js` `app.js` `img/full-moon.jpg` があれば動きます。

## 使い方

ローカルで見るときは、`index.html` をブラウザで開くだけです。

## 精度について

天文計算はおおまかな値です。朔望の時刻は数分程度、月までの距離は数百km程度の誤差があります。
潮回り（大潮・小潮など）は月齢による目安で、実際の潮の高さや時刻は場所によって異なります。
釣りや海辺の活動には、海上保安庁や気象庁の潮汐表を確認してください。
