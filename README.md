# moon-age-calendar

シンプルな月齢カレンダー。JavaScriptとSVGだけで動作し、外部ライブラリ不要。

## 特徴

- 依存ライブラリなし（1ファイルで完結）
- 月の満ち欠けをSVGで描画（半円＋楕円方式）
- 新月・上弦・満月・下弦のラベル自動表示
- 前月／次月ナビゲーション
- 今日の日付をハイライト
- CSSカスタムプロパティ対応（ダークテーマ等に自然に馴染む）

## 使い方

```html
<div id="moon-calendar"></div>
<script src="moonage.js"></script>
```

これだけで、当月の月齢カレンダーが表示されます。

## 精度について

朔望月（≈29.53日）による簡易計算です。

- 新月・満月：比較的正確
- 上弦・下弦：稀に±1日のズレが生じる場合があります

## カスタマイズ

月の画像を差し替えたい場合は、`moonage.js` 内の `moonSVG()` 関数を画像タグを返す形に書き換えるだけでOKです。
